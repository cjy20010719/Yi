# 翻译一下 1.0.0

macOS 划词、截图和输入翻译应用，支持 macOS 13+，包含 Apple Silicon 和 Intel 通用架构。

- Google 和有道翻译源切换，选择自动保存。
- 划词翻译、截图本机 OCR、混合语言识别、输入后自动翻译和快捷键设置。
- 四种气泡外观、背景深浅调节、长译文滚动和复制。
- 全新统一应用图标与透明菜单栏图案；菜单栏图标提前生成，避免运行时逐像素处理造成界面停顿。
- 开机静默启动、菜单中显示当前版本、Sparkle 签名自动更新。

下载 DMG，将「翻译一下.app」拖入 Applications。此版本使用本地临时签名，没有 Apple Developer ID 签名或公证；首次运行可能需要在 macOS 中允许打开，并按需授予划词和截图权限。

Google 和有道均使用免密钥接口，可能限流或变更。原文仅发送给所选翻译服务，截图在本机 OCR，不上传图片，不保存翻译历史。

已经安装相同 1.0.0 版本的用户需手动安装本次版本；以后的更高版本可通过应用内更新。临时签名可能导致系统权限需要重新授权。未在独立实体 Intel Mac 上实测。
